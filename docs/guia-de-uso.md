# POS SpArTaN Tech — Guía rápida del cobrador

> Una página. Imprímela y déjala junto a la caja.

## 1. Abrir caja (al empezar el turno)

1. Inicia sesión con tu usuario y contraseña.
2. La app te pide **abrir caja**. Escribe el **efectivo con el que empiezas** (el fondo).
3. Toca **Abrir caja**. Ya puedes vender.

_Solo puedes tener una caja abierta a la vez._

## 2. Cobrar una venta

1. Toca los **productos** para agregarlos al carrito (a la derecha).
2. Ajusta cantidades con **−** y **+**, o quita con la **✕**.
3. Toca **Cobrar**.
4. Elige el **método de pago**:
   - **Efectivo**: escribe (o toca un botón de monto) lo que te dio el cliente. La app calcula el **cambio**.
   - **Tarjeta** o **Transferencia**: no pide monto.
5. Toca **Confirmar venta**. El ticket se imprime solo.

_Si la impresora no responde, la venta **igual queda registrada**; aparece un aviso._

## 3. Cerrar caja (al terminar el turno)

1. Toca **Cerrar caja** (arriba del carrito).
2. Revisa el resumen del turno: verás el **efectivo esperado en caja**.
3. Cuenta el efectivo real y escríbelo en **Efectivo contado**.
4. La app muestra la **diferencia**:
   - **Verde** = sobra dinero.
   - **Rojo** = falta dinero.
5. Toca **Cerrar caja**. Se guarda un **respaldo automático** de los datos.

## Problemas comunes

| Situación                      | Qué hacer                                                           |
| ------------------------------ | ------------------------------------------------------------------- |
| "No hay una caja abierta"      | Abre caja antes de vender.                                          |
| El ticket no salió             | La venta está registrada. Reimprímela desde **Admin → Ventas**.     |
| Se cerró la sesión sola        | El acceso dura 8 horas. Vuelve a iniciar sesión.                    |
| "No se pudo conectar" al abrir | Cierra la app y vuelve a abrirla. Si sigue, avisa al administrador. |
