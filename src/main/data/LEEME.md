# Catálogos base

`catalogo-abarrotes-mx.json` se genera con `scripts/build-catalogo-abarrotes.ts` a partir de
**Open Food Facts** (https://world.openfoodfacts.org). Esos datos están bajo la
**Open Database License (ODbL) 1.0** (https://opendatacommons.org/licenses/odbl/1-0/): se
pueden usar y adaptar, citando la fuente, y este archivo derivado se comparte bajo la misma
licencia ODbL. El resto del sistema no queda sujeto a ella.

Formato: `items` = `[código, nombre, marca, presentación, categoría, unidad]`.
